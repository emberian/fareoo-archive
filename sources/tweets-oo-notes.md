- **2102235440774369599** (2026-09-22 03:16): "New refactoring! I'll do:
  `fix t m = Y (m t)` / `mix c p t s = c (p t s) s` / Instead of the current:
  `fix m t = Y (m t)` / `mix p c t s = c (p t s) s` / Or the original:

- **2102235443542851968** (same thread): the reason — "Wins: maximally simplify partial
  applications in the one most delicate step—fixpointing. - covariance of mix with
  traditional precedence list order and with function composition."

  "Composition of mixins, or as I call them 'modular extensions'—entities with a type as
  follows: `type ModExt inherited required newlyProvided = ∀ super, self : Type  self ⊂
  required self, super ⊂ inherited self ⇒ super → self → super∩(newlyProvided self)`".
  This supersedes `eoomi` §3.2's `Mixin inherited referenced defined`; note `required`
  and `inherited` are now type-level functions *of self*.
